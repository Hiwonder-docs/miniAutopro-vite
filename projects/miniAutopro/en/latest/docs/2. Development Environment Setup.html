2.1 Arduino IDE Installation and Interface Introduction ​

2.1.1 Arduino IDE Installation ​

Arduino IDE is a powerful software suite specifically designed for Arduino microcontrollers. The installation procedure remains consistent across versions. This section demonstrates the installation process using Arduino IDE 2.2.1 for Windows as an example.

NOTE

For the macOS installation method, refer to the documentation in the directory of this section.

  1. In the archive package under 2. Software Tools & Programs/1. Arduino Development Environment Setup, double-click ArduinoIDE-2.2.1.exe, as shown below. To download the latest software version, visit the official Arduino website at https://www.arduino.cc/en/software.
  1. Click I Agree to proceed with the installation.
  1. Retain the default settings and click Next to proceed to the next step.
  1. Click Browse to select the target installation path, then click Install to start the installation.
  1. Wait for the installation to finish.

NOTE

If prompted to install device drivers during the installation process, check "Always trust software from Arduino LLC" and click Install.

  1. After the installation is complete, click Finish.

2.2 Arduino IDE Settings and Configuration ​

2.2.1 Setting Arduino IDE Display Language ​

  1. To configure the interface language, select File -> Preferences in the Arduino IDE menu bar.
  1. In the pop-up window, locate the Language option to select the desired display language, then click OK.

2.2.2 ESP32 Package Installation ​

  1. If an ESP32 board support package has been installed previously and its version is not 3.3.11, follow step 2 to remove the older version. If no package was installed previously, or if version 3.3.11 is already installed, proceed directly to step 3.

  2. Removal methods:

Enter %LOCALAPPDATA%/Arduino15/packages into the File Explorer address bar and press Enter to open the directory, then delete the esp32 folder.

Alternatively, click Boards Manager on the left sidebar of the Arduino IDE interface, search for esp32, and remove the existing package.

  1. Installation method: Locate 2. Software Tools & Programs/1. Arduino Development Environment Setup/ESP32 Chip Package, open esp32_package_3.3.11_arduinome.exe, and wait for the installation process to complete.
  1. After the installation is complete, always select ESP32 Dev Module from the board list when compiling and uploading programs.

2.2.3 Arduino Program Upload ​

  1. This section demonstrates the upload process using a test routine that prints hiwonder. Under the same directory as this document, locate the 03 _Demo/Demo folder and double-click to open Demo.ino.
  1. Connect the ESP32 UNO board to the computer using a Type-C cable.
  1. Click the Select Board dropdown menu in the toolbar, then select the corresponding port. The assigned COM port number varies across computers and can be identified via Windows Device Manager. This section takes COM10 as an example.
  1. Search for esp32 dev module, select ESP32 Dev Module, and click OK.
  1. Click the Verify icon to compile the sketch and verify that no syntax errors exist.
  1. Once compilation succeeds, click the Upload icon to upload the program to the ESP32 UNO board.
  1. After the upload is complete, click the Serial Monitor icon to open Serial Monitor. The terminal displays the printed string hiwonder, as shown below.

NOTE

If the upload fails, lower the upload baud rate to 115200 and re-upload the sketch.
