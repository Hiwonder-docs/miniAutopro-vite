3. Factory Program Download ​

3.1 Program Download ​

NOTE

  • When connecting the Type-C download cable, toggle the battery switch to OFF to prevent the download cable from accidentally contacting the power pins of the expansion board and causing a short circuit.

  • The following steps use the motor automatic calibration program as a download reference.

  1. Locate and double-click the .ino file miniAutoPro-test.ino under the same directory as this document at Program Files/3.1 Encoder Motor Automatic Calibration Example/miniAutoPro-test/miniAutoPro-test.ino.
  1. Connect the ESP32 robot car board to the computer using a Type-C data cable.
  1. Select the development board model and communication port, as shown below:
  1. Click the upload button to download the program to the development board, and wait for the upload to complete.

NOTE

If burning fails after clicking the upload button, lower the upload baud rate to 115200 and upload again.

3.2 Motor Automatic Calibration ​

3.2.1 Program Download ​

NOTE

  • Refer to Section 3.1 Program Download. Select the program located at Program Files/3.1 Encoder Motor Automatic Calibration Example/miniAutoPro-test/miniAutoPro-test.ino for download.

  • This step is a prerequisite for all subsequent functions. Normal operation of the default factory program, including app remote control and AI voice control, relies on the motor dead zones and feedforward parameters calibrated in this section. Motor automatic calibration must be completed before downloading and running the factory program, otherwise the robot car will move abnormally.

3.2.2 Program Outcome ​

NOTE

Automatic calibration takes approximately 3 minutes. The buzzer sounds twice: the first time signals system startup, and the second time confirms calibration completion. Confirm successful calibration only after the second buzzer prompt sounds and the robot car begins moving forward. Do not disconnect the power during this process.

After the program download is complete, power on the robot car. The system executes the following sequence:

  1. Device Self-Test: The serial monitor outputs the expansion board device ID, the firmware version, and the current battery voltage, displayed in both millivolts and volts.

  2. Buzzer Startup Prompt: The buzzer emits three ascending tones in sequence, indicating that the system has started.

  3. Automatic Calibration of 4-Channel Encoder Motors: The chassis driver board automatically calibrates the 4 motors sequentially in forward and reverse directions. It measures and records forward and reverse starting dead zones, representing minimum starting PWM values, running dead zones, representing minimum running PWM values, and feedforward parameters in PWM per RPM. The calibration process allows a maximum timeout of 300 s. If a timeout or failure occurs, corresponding error messages appear in the serial monitor.

  4. Calibration Result Output: After successful calibration, the serial monitor outputs complete calibration data for the 4 motors in forward and reverse directions, including starting dead zones, running dead zones, and feedforward coefficients.

  5. Calibration Completion Prompt: The buzzer emits three descending tones in reverse sequence, confirming successful calibration.

  6. Motion Verification Test: The robot car travels forward at a speed of 0.15 m/s for 10 s and stops automatically, verifying that motor drive and chassis motion functions operate normally.

3.3 Factory Program Download ​

This section covers the procedure for downloading the default factory program to the robot car.

3.3.1 Program Download ​

NOTE

  • Refer to Section 3.1 Program Download. Select the program located at Program Files/3.2 Factory Program Download/MiniAutoPro_Default/MiniAutoPro_Default.ino for download.

  • Before running the program, Section 3.2 Motor Automatic Calibration must be completed. Otherwise, the robot car will experience abnormal movements, such as failing to travel straight or deviating during turns.

3.3.2 Program Outcome ​

After the program download is complete, power on the robot car. The serial monitor outputs system initialization information. The Mecanum-wheel chassis, BLE Bluetooth, ultrasonic sensor, and robotic arm servos initialize sequentially, and the buzzer emits a startup prompt tone.

The default factory program integrates the following features:

  1. miniAuto App Bluetooth Remote Control: Supports joystick control, ultrasonic obstacle avoidance, RGB color adjustment, gripper and robotic arm control, and sensor telemetry transmission. For detailed instructions, refer to 4. Quick Start.

  2. WonderLLM AI Voice Interaction: When equipped with the WonderLLM module, natural language commands entered through the online chat interface in the app control the movement of the car and robotic arm actions. For detailed instructions, refer to subsequent AI model fundamental tutorials.

NOTE

  • If the WonderLLM module is not detected at startup, the program automatically retries initialization every 5 s, during which the app remote control function remains unaffected.

  • App remote control and AI voice interaction can be used simultaneously, as internal control coordination is implemented within the program.
